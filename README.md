# Data Analyst

[Відкрити застосунок](https://data-analyst-iansts.streamlit.app/) · [Код](https://github.com/iansts/data-analyst)

Українськомовний LLM-агент для перевірки якості CSV та Excel. Досліджує дані через Python-інструменти, уточнює неоднозначності й пропонує виправлення з попереднім переглядом. Зміни застосовуються лише після підтвердження користувачем.

## Можливості

- Профіль таблиці, пошук рядків, перевірка колонок і групові обчислення.
- План виправлень, підтвердження, відхилення й відкат.
- Графіки та експорт CSV, XLSX і журналу JSON.
- Автоматичні повтори запитів при тимчасових лімітах і скорочення старих результатів інструментів у контексті.

Використовується Groq, модель `openai/gpt-oss-120b`. Власний API-ключ вводиться у приховане поле; без ключа аналіз не виконується. Частини даних надсилаються Groq після згоди користувача. Файли, історія та ключ зберігаються лише в пам’яті сесії. Завантажте результат перед виходом.

## Локальний запуск

Потрібен Python 3.11 або новіший.

```sh
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud

Виберіть цей GitHub-репозиторій, гілку `main`, файл `app.py` та Python 3.11. Секрети сервера не потрібні: кожен користувач вводить власний ключ. Docker не використовується.

## Перевірка

```sh
pip install -r requirements-dev.txt
python -m pytest -q
```

У `examples/rentals.csv` містяться вигадані дані для демонстрації; інструкція — `examples/TEST_SCENARIO.md`. Тести API використовують контрольовані відповіді лише в тестах, не в застосунку.

## Межі

До 10 МБ, 20 000 рядків і 60 колонок. CSV-налаштування визначаються автоматично. XLSX відкривається як значення першого аркуша, без перенесення формул і форматування. API-ліміти та якість відповідей залежать від Groq. Опис системи для навчального завдання — у `SUBMISSION.md`.
